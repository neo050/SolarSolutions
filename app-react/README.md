# Electrician Landing Page

This project is a simple React application built with TypeScript and styled using Tailwind CSS. It serves as a landing page for an electrician service.

## Project Structure

```
electrician-landing-page
├── public
│   └── index.html
├── src
│   ├── App.tsx
│   ├── main.tsx
│   ├── components
│   │   └── LandingPage.tsx
│   └── types
│       └── index.ts
├── package.json
├── postcss.config.js
├── tailwind.config.js
├── tsconfig.json
└── README.md
```

## Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd electrician-landing-page
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the application**:
   ```bash
   npm start
   ```

4. **Open your browser** and navigate to `http://localhost:3000` to see the landing page.

## Usage

The landing page provides information about the electrician services offered. You can customize the content in `src/components/LandingPage.tsx` to fit your needs.
